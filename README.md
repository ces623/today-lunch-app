# 오늘점심 (Today Lunch Recommender)

오늘의 기분, 다이어트 여부, 음식 종류(한식·중식·일식·양식), 1인당 예산, 매운 음식 가능 여부, 식사 인원(혼밥/함께 식사)을 선택하면 조건에 딱 맞는 **맞춤 점심 메뉴 3가지**와 **한 줄 추천 이유**를 알려주는 React + TypeScript 기반 웹 애플리케이션입니다.

---

## 주요 기능

1. **6단계 직관적 조건 선택**
   - **오늘의 기분**: `😊 행복해요` / `😫 피곤해요` / `😡 스트레스 받아요` / `💪 든든하게 먹고 싶어요`
   - **다이어트 여부**: 일반 식사 / 다이어트 중 (저칼로리·고단백 식단 우선 추천)
   - **음식 종류**: 한식 / 중식 / 일식 / 양식 / 전체 종류
   - **1인당 예산**: 빠른 금액 버튼 및 7,000원 ~ 20,000원 세밀 슬라이더
   - **매운 음식 가능 여부**: 가능 / 불가능(순한맛만) / 매콤한 메뉴만
   - **식사 형태**: 혼밥(1인 식사) / 함께 식사(2인 이상)
2. **맞춤 메뉴 3선 & 한 줄 추천 이유**
   - 메뉴 이름, 예상 가격, 예상 열량(`kcal`), **한 줄 추천 이유**, 기분·상황 맞춤 포인트, 맛있게 먹는 팁 제공
   - **[다른 메뉴 조합 보기]** 버튼으로 조건에 맞는 새로운 3가지 조합 즉시 탐색
3. **편의 기능**
   - 마음에 드는 메뉴 **찜하기(보관함)** 및 **메뉴명 원클릭 복사**
   - 카테고리별 **전체 점심 메뉴판** 조회

## 프로젝트 폴더 구조

```text
├── index.html            # 앱 진입점 HTML (한국어 메타 태그 및 웹폰트 설정)
├── package.json          # React + TypeScript 의존성 및 빌드 스크립트
├── tsconfig.json         # TypeScript 컴파일 설정
├── vite.config.ts        # Vite 번들러 및 Tailwind CSS 빌드 설정
├── vercel.json           # 정적 웹 호스팅(Vercel 등) 배포 설정
├── .gitignore            # Git 업로드 제외 파일 설정 (node_modules, dist 등)
└── src/
    ├── main.tsx          # React 루트 마운트 파일
    ├── index.css         # Tailwind CSS 및 커스텀 폰트 설정
    ├── App.tsx           # 메인 화면 및 점심 추천 알고리즘 컴포넌트
    └── data/
        └── menus.ts      # 한식·중식·일식·양식 점심 메뉴 큐레이션 데이터셋
```

## 로컬 실행 및 빌드 방법

별도의 환경변수나 외부 API 설정 없이 아래 명령어로 바로 실행 및 빌드할 수 있습니다.

```bash
# 1. 의존성 패키지 설치
npm install

# 2. 로컬 개발 서버 실행
npm run dev

# 3. 프로덕션 배포용 정적 파일 빌드 (dist/ 폴더 생성)
npm run build

# 4. 빌드된 결과물 미리보기
npm run preview
```

## 웹 호스팅 배포 안내

- 본 프로젝트는 외부 API, 별도의 서버 URL, 환경변수를 전혀 사용하지 않는 순수 클라이언트(React + TypeScript) 정적 웹 애플리케이션입니다.
- GitHub 저장소에서 내려받은 뒤 `npm install` 및 `npm run build`를 실행해 생성된 `dist` 폴더를 Vercel, Netlify, GitHub Pages 등 일반적인 정적 웹 호스팅 서비스에 그대로 배포할 수 있습니다.
